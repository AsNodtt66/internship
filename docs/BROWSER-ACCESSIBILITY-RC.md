# Browser, Mobile and Accessibility RC Checklist

P5 established an accessibility baseline. P7 requires real browser evidence.

For each supported browser/viewport record PASS/FAIL for:

- landing skip link and landmarks;
- visible keyboard focus;
- no keyboard trap in Filament modal/actions;
- form label/instruction association;
- errors understandable without relying only on color;
- tables usable at mobile widths;
- 200% zoom/reflow;
- status/progress understandable by text;
- session-expired flow returns to correct panel;
- confirmation dialog explains destructive/business-sensitive actions.

Recommended manual assistive technology pass: NVDA + Firefox/Chrome on Windows; VoiceOver + Safari where available.
